# **Design System – Couleurs & Typographie**

## **1\. Objectif du document**

Ce document définit les règles de base concernant les couleurs et la typographie utilisées dans l’application.  
 Il vise à garantir une interface cohérente, lisible et adaptable aux différentes entreprises utilisant la plateforme.

## **2\. Principes généraux**

* L’interface doit rester neutre et professionnelle  
* Les couleurs d’entreprise ne doivent pas impacter la lisibilité  
* La typographie doit être lisible sur tous les écrans  
* Le design doit être compatible avec un mode clair (light mode)

## **3\. Palette de couleurs**

### **3.1 Couleurs système (interface par défaut)**

Ces couleurs sont utilisées pour la structure globale de l’application.

| Usage | Couleur |
| ----- | ----- |
| Fond principal | `#FFFFFF` |
| Fond secondaire | `#F9FAFB` |
| Cartes / sections | `#FFFFFF` |
| Bordures | `#E5E7EB` |
| Texte principal | `#111827` |
| Texte secondaire | `#6B7280` |

### **3.2 Couleur principale (branding entreprise)**

Chaque entreprise peut définir **une couleur principale** utilisée comme accent visuel.

**Exemple (entreprise par défaut)** :

* Couleur principale : `#005F02`  
* Hover / variation : `#427A43`  
* Accent léger : `#C0B87A`  
* Accent doux : `#F2E3BB`

📌 Cette couleur est utilisée pour :

* boutons principaux  
* liens  
* éléments actifs  
* indicateurs visuels

📌 Elle ne doit **jamais** être utilisée comme couleur de fond principale.

### **3.3 Règles d’utilisation des couleurs**

* Le fond principal reste blanc en mode clair  
* La couleur d’entreprise est utilisée comme accent  
* Le contraste texte/fond doit toujours être suffisant  
* Les couleurs doivent rester cohérentes sur toutes les pages

## **4\. Typographie**

### **4.1 Police utilisée**

L’application utilise la police **Source Sans 3**, une typographie sans empattement optimisée pour la lisibilité des interfaces utilisateur.

### **4.2 Hiérarchie typographique**

| Élément | Police | Poids |
| ----- | ----- | ----- |
| Titre principal (H1) | Source Sans 3 | 700 |
| Titre secondaire (H2) | Source Sans 3 | 600 |
| Sous-section (H3) | Source Sans 3 | 600 |
| Texte principal | Source Sans 3 | 400 |
| Labels / boutons | Source Sans 3 | 500 |
| Texte secondaire | Source Sans 3 | 400 |

### **4.3 Tailles recommandées**

* H1 : 22–24 px  
* H2 : 18–20 px  
* Texte normal : 14–15 px  
* Texte secondaire : 12–13 px

### **4.4 Règles typographiques**

* Une seule police est utilisée dans toute l’application  
* Les titres sont différenciés par le poids et la taille  
* Les textes doivent rester lisibles sur fond clair  
* Les couleurs de texte respectent la palette système

## **5\. Évolutivité**

Ce design system peut évoluer :

* ajout d’un mode sombre  
* ajout d’une police dédiée aux titres  
* personnalisation avancée par entreprise

## **6\. Conclusion**

Ce document constitue la référence visuelle de l’application.  
 Il garantit une interface cohérente, professionnelle et adaptable à un contexte multi-entreprises.
